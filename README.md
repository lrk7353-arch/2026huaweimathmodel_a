最新导出覆盖1500/1500个配置，均有官方成功记录；第六轮新增25个配置降时，保留方案无回退，其中P1/P2/P3分别3/5/17个。新增固定分核的P3关键读序精修及统一预算组合，并通过同方案P2/P3复评分开排程与缓存收益。P1又验证4张大图，另3张图完整冷启动分别约36、48、142秒，各完成12次新评测。完整覆盖不代表达到最优，也不代表建模研究与竞赛材料已经全部完成。

历史评测缓存、重复快照、旧交接包和其他选题不纳入版本控制；这些文件仍保留在原电脑上。成绩表中的官方记录路径和部分实验报告链接指向本机历史记录，新克隆中不会自动包含它们。

当前直接迭代入口默认精修本机历史最好方案，因此默认模式依赖未入库的历史实验记录。换电脑时使用 `--incumbent-plan` 指定入库的精选方案，即可在新环境中先官方复评再精修，无需旧实验目录；详见新入口说明。P1 也可使用 `--from-scratch` 模式，其他从头求解方式见原求解器说明。
