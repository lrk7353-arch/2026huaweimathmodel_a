# 华为数学建模 A 题研究

本地研究仓库，包含 A 题求解器代码、官方附件数据与评测器、分析报告，以及本轮精选方案。

- 最新结果：`A题研究/直接迭代/本轮成果/本轮结果.md`
- 精选方案：`A题研究/直接迭代/本轮成果/方案/`
- 新入口说明：`A题研究/直接迭代/README.md`
- 原统一求解入口：`A题研究/精修求解器/solve.py`

本轮导出覆盖 1227/1500 个配置：2—5 核全部齐全，1 核有 27 个。这里保存的是阶段成果，不代表比赛最终交付已经完成。

历史评测缓存、重复快照、旧交接包和其他选题不纳入版本控制；这些文件仍保留在原电脑上。成绩表中的官方记录路径和部分实验报告链接指向本机历史记录，新克隆中不会自动包含它们。

当前直接迭代入口默认精修本机历史最好方案，因此依赖未入库的历史实验记录；克隆后不能直接使用该默认模式。P1 可使用说明中的 `--from-scratch` 模式，其他从头求解方式见原求解器说明。精选方案 JSON 本身可直接用于官方评测。
