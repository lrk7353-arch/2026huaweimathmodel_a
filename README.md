本分支最新交付见[三指标联合推进执行结果](A题研究/直接迭代/三指标联合推进_20260926/执行结果.md)与[使用、复现和回滚](A题研究/直接迭代/三指标联合推进_20260926/使用与回滚.md)。完整1500配置索引在`A题研究/直接迭代/三指标联合推进_20260926/累计1500配置成绩.csv`，新精选覆盖旧库的19个配置，均已独立复评；五核100图平均加速比为P1 **3.81848314**、P2 **4.56151717**、P3 **4.67933360**。这些是累计精选成绩，不是固定预算从头成绩，也不是官方总分。`plan`相对于该CSV目录解析，整个仓库包含全部依赖方案。

本轮实现关键等待、驻留、分核与FIFO读序的联合候选。54臂暖启动比较中P2/P3有效，64臂从头B24整合未通过冻结门槛，因此只交付精选收益与`wait_search.py`可选精修入口，不替换成熟默认，不启动最终1500从头重跑。25项相关测试、1500项交付审计通过，完整P3五核100图缓存指标已补齐。开始前重点标签`milestone/three-metric-plan-approved-20260926`固定于`d0090c6`，本轮最终标签为`milestone/three-metric-evaluated-20260926`；开发分支`codex/critical-wait-joint`，主分支未合并。

上一轮[联合整合结果](A题研究/直接迭代/联合整合_20260926/执行结果.md)的完整基础库仍位于`A题研究/直接迭代/联合整合_20260926/最终累计/`，以下为当时的实验与版本说明。
