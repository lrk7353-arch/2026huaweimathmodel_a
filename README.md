华为数学建模 A 题研究仓库，包含求解器、官方附件与评测器、第一至第十三轮成果，以及双方成果整合后的完整精选库。

本分支最新交付见[联合整合执行结果](A题研究/直接迭代/联合整合_20260926/执行结果.md)与[使用、复现和回滚](A题研究/直接迭代/联合整合_20260926/使用与回滚.md)。完整1500份方案在`A题研究/直接迭代/联合整合_20260926/最终累计/`，五核100图平均加速比为P1 **3.81552207**、P2 **4.54636927**、P3 **4.66624686**。这些是累计精选成绩，不是固定预算从头成绩，也不是官方总分。

整合前重点标签`milestone/pre-integration-20260925`固定于`238aafe`，已同步GitHub。分支为`codex/joint-integration-v3`，主分支未合并。

后续研究见[Makespan、搬运与缓存协同研究](A题研究/直接迭代/三指标协同研究_20260926/研究结论与下一步.md)及[近两年文献与可迁移性](A题研究/直接迭代/三指标协同研究_20260926/文献与可迁移性.md)。研究分支`codex/memory-aware-research`读取当前300份五核计划和2042个历史候选，提出等待感知的区域联合搜索；未改变求解器、未新增官方调用，以上成绩不变。已验证整合版本由标签`milestone/joint-integration-evaluated-20260926`（`8597827`）保留。

历史评测缓存、重复快照、旧交接包和其他选题不纳入版本控制；这些文件仍保留在原电脑上。成绩表中的官方记录路径和部分实验报告链接指向本机历史记录，新克隆中不会自动包含它们。

当前直接迭代入口默认精修本机历史最好方案，因此默认模式依赖未入库的历史实验记录。换电脑时使用 `--incumbent-plan` 指定入库的精选方案，即可在新环境中先官方复评再精修，无需旧实验目录；详见新入口说明。P1 也可使用 `--from-scratch` 模式，其他从头求解方式见原求解器说明。
