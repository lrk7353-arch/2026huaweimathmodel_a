# 完整从头1500配置

100图×3问题×1—5核，全部有合法输出。官方输入、配置、代码哈希和完整有序方案哈希已核对，最佳方案均来自已付费的成功调用；已通过`export_cold_runs.py restore`恢复1500份计划。

五核均值：P1 **3.70923028**，P2 **4.44156894**，P3 **4.59947608**。这是本轮统一流程的从头结果；各配置B24基础预算，P1有47项跨主机重跑、7项缺解后的时间扩展，全部成本保留。不是一次严格240秒协议全部成功的报告。

- `从头1500配置成绩.csv`：逐配置时间、COPY、spill、P3字节命中、调用、失败、生成时间、恢复标记和同一次B24轨迹的预算前缀。
- `按问题与核数汇总.csv`：每个问题、每个核数的100图均值。
- `plans.tar.gz`：全部1500份计划；`selected_records.json`：对应官方最佳记录。
- `all_calls.jsonl.gz`：逐运行全部调用，包括失败和7项恢复调用；`prior_failed_runs.jsonl.gz`：47项远端缺解的188次先前失败调用。
- `export_manifest.json`：全量完整性、输入/源文件哈希与预算汇总。29,956次所选从头运行调用，加188次先前失败，合计30,144次；包含592次失败。
- `cold_vs_selected.png/.pdf`：与历史及最终累计库分开的核数曲线，不作为不同搜索预算之间的因果对照。
