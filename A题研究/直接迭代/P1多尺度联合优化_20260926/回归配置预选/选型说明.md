# 六配置回归预选

选择仅依据100张原始图的GraphIR结构统计，不读取这些配置的新方法效果。排除本轮开发图047/075/085；优先小中规模，按独立分量、分支密度、输入规模、最大分量工作集中度覆盖结构差异。它们是本次新增回归配置，不声称是整个项目从未用于任何开发的严格留出测试集。

|图|n5计算操作数|WCC数|最大WCC操作数|分叉/汇合操作|结构侧重|
|---|---:|---:|---:|---:|---|
|004|777|111|7|111/222|大量同样大小的独立小块，防止联合局部搜索损伤容易并行的结构|
|044|1364|11|124|264/264|根输入952928B，静态根输入搬运/五核平均总计算比0.941，关注输入通信代价|
|048|1728|1|1728|537/777|单大连通分量，分叉汇合密集，M/V总work约54/46|
|035|3857|16|2430|750/1434|最大分量占59.83%总work，M约30.18%，工作量不均且偏V管线|

额外两个低核配置：044 n2、035 n3。前者对照降低并行度后的输入通信情形，后者检查大分量与不均衡分配的核数敏感性。

所有配置均P1；每个配置比较成熟 integrated 和显式 joint_tonight，B24/240秒，共享相同协议及随机种子，各自从头运行。配置选型不改变算法的全局通用性，不把图号写入候选策略。

静态输入比值定义为 `root_input_bytes / 60 / (total_compute_cycles / 5)`，只做样本分层，并不是官方DDR争用率或瓶颈证明。操作数也只用于控制预期规模，不保证240秒内可用满24次额度。

全100图原始特征保存在 `仅原图结构.csv`，六配置清单见 `六配置.json`。
