## 哪些非单调路径确实发生过

044、049、069的beam最终选中解，都来自实际扩展过的变差祖先，并非事后拼接。049的真实路径为：

`97671 → 87404 → 88008 → 87805 → 86882 → 86523`

其中87404→88008确实先变差；随后后代改善。不过在相同26次trial处，beam仍慢于greedy，所以这只说明本次较大预算搜索经过了可用的非单调路径。

069更明显：`11695 → 11736 → 11865 → 12157 → 11923 → 11526`。各层均按当时globalbest的8%窗口验收。这也不证明其他可能的单路径策略到不了最终解。

## 更值得继续验证的机制

保优greedy在一轮停滞之后，换下一轮算子仍可能改善：

- 049：`97671 → 87404 → 87083 → 87083 → 86996`。
- 069：`11695 → 11635 → 11596 → 11596 → 11595`。
- 071：`9304 → 9218 → 9218 → 9211`。
- 082：`238028 → 218027 → 218024 → 218024 → 217970`。

这些记录支持单独研究“保留incumbent、继续轮换邻域”，不能把一轮不改善等同于整个轮换周期无解。它仍需要预算与轮数边界。正式fairv2源码和既有评分没有修改；本目录的额外预算结果单独保留。
