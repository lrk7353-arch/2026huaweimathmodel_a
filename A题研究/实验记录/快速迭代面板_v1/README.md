# 快速迭代面板 v1

这是一份按结构固定的开发筛选面板，不是独立未见测试集。此前100图已查看或实验，最终收益仍需全100图验证。选图过程未读取性能结果，未执行官方评估。

- 开发12图（固定顺序）：`052,051,021,095,078,002,071,037,029,013,088,044`。
- 扩展24图（与开发12图不重叠）：`089,075,067,020,007,004,019,043,050,074,063,006,008,027,001,048,098,045,100,024,081,031,083,080`。
- 单列压力4图：`014,016,062,053`。全部19个大图压力池另列在生成清单中，不进入默认快速循环。

开发池限制计算节点≤4000，扩展池≤10000；分别覆盖12图和额外24图。12项结构特征经全100图并列中秩变换后，用确定性medoid起点与最远覆盖选择；并列按图名排序，不含题号特判、随机数或收益排序。较小计算节点数只是成本代理，不能保证每次模拟都快。

开发面板含3个单计算分量图、2个纯V图、7个跨分量共享输入图，6个图的原始输入超过1 MiB。计算节点范围741–3920。扩展面板范围600–9309，补充4个单分量图、4个纯V图和15个跨分量共享输入图。这些覆盖统计不是性能结论。

文件：

- `selection/panels.json`：精确顺序、阈值、算法、逐步选择距离。
- `selection/README.md`：每图的结构理由、指标定义和使用边界。
- `selection/panel_table.csv`：所选40图全部结构特征。
- `selection/all_features.csv`：100图特征。
- `selection/manifest.json`：100个原图、配置、结构文件、脚本与产物SHA256；输入读取前后已核对。
- `selection/*.cases.txt`：三个面板的case名称，一行一个。
- `validation.json`：9项测试通过；在新的临时输出目录重建后，全部8个产物逐字节一致。官方调用0次。

复现（Python标准库，输出必须是新目录）：

```bash
python3 -B A题研究/实验记录/快速迭代面板_v1/build_panels.py --output /tmp/a-panels-reproduction
python3 -B -m unittest discover -s A题研究/实验记录/快速迭代面板_v1 -p test_build_panels.py -v
```
